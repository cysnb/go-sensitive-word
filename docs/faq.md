# 常见问题

**Q: 为什么添加词条后立即查询不到？**

词库变更通过后台通道异步应用到过滤器。调用 `WaitForSync(ctx)` 等待应用完成。

**Q: DFA 和 AC 怎么选？**

小词库、频繁更新选 DFA；大词库、长文本、高并发选 AC。详见[算法选择](algorithm-guide.md)。

**Q: `FilterAc` 和 `FilterAC` 有什么区别？**

没有区别，两个常量值相同，用于兼容两个上游工程的命名。

**Q: 为什么 `FindAll` 返回的是原文而不是小写？**

归一化只用于匹配判断，结果始终映射回原文片段，便于展示与替换。

**Q: 如何防止大小写、全角绕过？**

默认配置已启用忽略大小写与全角转半角。

**Q: 如何防止零宽字符、繁简、同形字绕过？**

使用 `WithStrictNormalizer()`，或自定义 `NormalizerConfig`。

**Q: 一个词可以有多个来源吗？**

可以，多次以不同来源调用 `AddWordsWithSource` 即可。

**Q: 删除词后来源会保留吗？**

不会，删除词条时同时清理其来源记录。

**Q: 关闭后再操作会怎样？**

返回 `store.ErrStoreClosed`，不会 panic。

**Q: 全量加载词库会不会很慢？**

约 5.1 万词。建议按业务需要选择分类加载。AC 首次构建与批量重建开销高于 DFA。

**Q: 测试为什么不用 `time.Sleep`？**

使用 `WaitForSync` 确定性等待，避免因机器性能导致的偶发失败。
